# @void/deploy-core

Shared deployment contracts for [Void](https://void.cloud) runtimes and deployment adapters. Includes manifests, progress events, routing rules, resource plans, and SQL and Durable Object migration metadata.

This package works in Node.js and Cloudflare Workers. To deploy an application, use the `void` CLI.

## Documentation

See [Deployment](https://void.cloud/guide/deployment) for deploying an app and [Platform Development](https://void.cloud/guide/platform-development) for building a runtime or adapter.

Read the [Void documentation](https://void.cloud) online or use the Markdown guides and references in `node_modules/void/docs/`, included with the `void` package.
