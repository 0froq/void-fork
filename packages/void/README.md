# void

Build and deploy full-stack Vite apps on Cloudflare Workers. Void provides server routes, server-rendered pages, and typed access to databases, storage, and AI.

## Getting Started

Use Node.js 24.21.0 or later. In an empty directory, run:

```sh
npm install -D void
npx void init
npm run dev
```

Choose a UI framework, starter, and deployment target. Then deploy:

```sh
npx void deploy
```

Void builds your app, provisions its resources, applies migrations, and prints the deployed URL.

Follow the [Quickstart](https://void.cloud/guide/quickstart) for your first app or to add Void to an existing project.
