# @void/deploy-cloudflare

Cloudflare deployment primitives used by the [Void CLI](https://void.cloud/reference/cli). Provides Worker configuration reads, uploads, activation, and deployment verification for runtime and adapter authors.

To deploy an application to your Cloudflare account, run `void deploy --platform cloudflare`.

## Documentation

See the [Cloudflare guide](https://void.cloud/integrations/cloudflare) for configuration and credentials, or [Platform Development](https://void.cloud/guide/platform-development) for building a runtime or adapter.

Read the [Void documentation](https://void.cloud) online or use the Markdown guides and references in `node_modules/void/docs/`, included with the `void` package.
